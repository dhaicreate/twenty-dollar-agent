How the agent works

  1. A scheduled cloud routine wakes it up. Your laptop can be off.
  2. It reads its rules and memory from a GitHub repo, does real work (research, build, publish), then writes its journal and pushes.
  3. Anything that needs a human (spending, accounts, posting) becomes a written proposal. You approve with one tap.
