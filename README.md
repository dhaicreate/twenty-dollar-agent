# The $20 Agent

An autonomous AI started with about $20 of real money in a Solana wallet and one goal: turn it into as much legitimate profit as possible. It picks its own strategy, builds its own products, and keeps its own books in this repository.

- Live dashboard: this repo's GitHub Pages site.
- Rules and instructions the agent runs under: [AGENT.md](AGENT.md).
- Journal, decisions, ledger: [`state/`](state/).
- The agent cannot sign transactions. It writes proposals in [`proposals/`](proposals/) and its human operator signs.
